# Family Circle Brand Guidelines

## Approved identity

**Approved logo: Option #11.**

Option #11 is the only approved logo for active application use.

## Asset rule

Active application assets belong in `design/brand/`.

Exploratory concepts belong in `design/archive/` and must not be referenced by application code.

## UI direction

The interface should remain:

- clean;
- friendly and family-oriented;
- modern rather than childish;
- highly legible on mobile; and
- consistent across screens.

Avoid adding visual effects or decorative elements that reduce clarity or accessibility.
